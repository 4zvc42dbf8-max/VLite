VLite : mise en place (une seule fois)

1. Dépose TOUS ces fichiers dans le dépôt GitHub (y compris le dossier .github).
   Sur iPhone, si le dossier .github pose problème : Add file > Create new file, nom
   ".github/workflows/collect.yml", puis colle le contenu du fichier collect.yml.
2. Settings > Pages : Deploy from a branch, branche main, dossier /(root).
3. Settings > Actions > General > Workflow permissions : "Read and write permissions".
4. Onglet Actions > "Collecte VLite" > Run workflow. Après ~1 minute, videos.json apparaît.
5. Ouvre l'app (Safari > Partager > Sur l'écran d'accueil).

Le collecteur tourne ensuite tout seul toutes les 20 minutes.
Pour ajouter une chaîne : dans l'app (+), ou modifie channels.json dans le dépôt.

Le collecteur (toutes les 20 min) envoie une notification par nouvelle vidéo (groupées au-delà de 3).
